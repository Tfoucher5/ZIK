# v2.7.0 — Profil à onglets, stats par mode & Early Adopter automatique

## Contexte

Suite de la v2.6.x : le profil mélangeait tout sur une seule page et les scores QCM (jusqu'à 1 000 pts/manche) écrasaient visuellement les scores du mode classique (1-3 pts/manche). Le succès Early Adopter devait aussi être attribué à la main.

## Migrations appliquées (prod ✅)

- `20260611_early_adopter_auto.sql` — description mise à jour, contrainte `UNIQUE NULLS NOT DISTINCT` sur `user_achievements` (corrige l'unicité des succès one_time à tier NULL), backfill : **215 comptes** créés avant le 1er juin 2026 ont reçu 🌟 Early Adopter.
- `20260611_games_mode.sql` — colonne `games.mode` (`classic` | `qcm`, défaut `classic`), backfill depuis `rooms.game_mode` pour les rooms persistantes.

## Ce qui change

### 🌟 Early Adopter automatique

- Critère : compte créé avant le **1er juin 2026** (heure de Paris) — 3 mois de joueurs précurseurs.
- Backfill fait en base + vérification automatique dans `checkAchievements` pour les futurs cas (aucune attribution manuelle).

### 👤 Profil à onglets

- Deux onglets sous le hero : **📊 Statistiques** et **🏅 Succès** (profil perso et profil public).
- L'onglet Succès contient les séries de jeu + la grille de succès filtrable.

### 🎤/🎨 Stats séparées par mode

- `games.mode` est désormais renseigné à la création de chaque partie (`game.js`).
- L'API `/api/stats/[userId]` calcule tout en double : champs historiques = mode classique (compatibilité), nouvel objet `qcm` avec les mêmes agrégats.
- `ProfileStats` : switcher **🎤 Classique / 🎨 QCM** qui pilote les cartes de stats, la courbe d'évolution, la répartition, les meilleurs scores par room et l'historique.
- En mode QCM : pas d'ELO (remplacé par la carte Meilleur score), scores formatés en k.

### Limites connues

- Les parties QCM jouées dans des rooms éphémères avant la v2.7.0 restent comptées en classique (la room n'existant plus, le mode n'est pas retrouvable). Les nouvelles parties sont correctement taguées.

## Fichiers principaux

- `src/lib/server/services/achievements.js` — early_adopter auto
- `src/lib/server/socket/game.js` — `mode` sur l'insert games
- `src/routes/(site)/api/stats/[userId]/+server.js` — stats par mode (`buildModeStats`)
- `src/lib/components/ProfileStats.svelte` — switcher de mode
- `src/routes/(site)/profile/+page.svelte`, `src/routes/(site)/user/[username]/+page.svelte` — onglets
