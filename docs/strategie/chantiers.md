# Chantiers

Ce qui est en cours et ce qui reste à faire, affiché dans le QG (bloc « Chantiers »). Tenu à jour par la session CEO à chaque lancement, rendu ou fusion. Une section par chantier, le plus important en haut :

```
## Titre
- **Statut** : en cours | à faire | fait
- **Équipe** : …
- **Prochaine étape** : …
```

Un chantier fini passe en `fait`, puis est retiré à la release suivante.
