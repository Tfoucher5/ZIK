# Intégration AdSense — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pubs display discrètes intégrées au design, invisibles pour les super_admins, jamais pendant le gameplay, avec CMP Google et conformité RGPD.

**Architecture:** Un composant `AdSlot.svelte` (cadre Aurora Glass + `<ins class="adsbygoogle">`, hauteur fixe réservée) consommant le contexte `zik` du layout ; le script `adsbygoogle.js` injecté dynamiquement dans `(site)/+layout.svelte` uniquement quand l'auth est résolue et que l'utilisateur n'est pas super_admin ; slots configurés dans `src/lib/ads.js` (un slot vide ⇒ rien ne se rend).

**Tech Stack:** SvelteKit 2 / Svelte 5 runes, Google AdSense (unités display manuelles, taille fixe), CMP Google « Privacy & messaging ».

## Global Constraints

- Client AdSense : `ca-pub-6495356963886902`.
- **Aucun Auto ad, aucune vignette, aucune ancre** — unités manuelles uniquement.
- Admin (`user.profile.role === 'super_admin'`) : ni script, ni bannière, ni pub.
- Aucune pub pendant une manche ni dans le Mode Salon.
- Zéro layout shift : hauteur toujours réservée quand l'encart est affiché.
- PAS de bump de version (branche v3.0.0, bump au merge).
- Demander confirmation utilisateur avant chaque `git commit`.
- `npm run lint` doit passer avant PR.
- Spec : `docs/superpowers/specs/2026-07-08-adsense-design.md`.

### Task 2: Composant `AdSlot.svelte`

**Files:**

- Create: `src/lib/components/AdSlot.svelte`

**Interfaces:**

- Consumes: contexte `zik` du layout (`user`, `authReady`), `AD_SLOTS`/`ADSENSE_CLIENT` de Task 1.
- Produces: `<AdSlot adSlot={AD_SLOTS.content} height={100} />` — ne rend rien si admin, auth non résolue, ou slot vide. (`adSlot` et non `slot` : `slot` est un attribut réservé Svelte.)

- [ ] **Step 1: Créer le composant**

```svelte
<script>
  import { getContext } from 'svelte';
  import { ADSENSE_CLIENT } from '$lib/ads.js';

  let { adSlot = '', height = 100 } = $props();

  const zik = getContext('zik');
  const show = $derived(
    !!adSlot && zik.authReady && zik.user?.profile?.role !== 'super_admin'
  );

  let insEl = $state(null);
  let pushed = false;

  $effect(() => {
    if (insEl && !pushed) {
      pushed = true;
      try {
        (window.adsbygoogle = window.adsbygoogle || []).push({});
      } catch { /* bloqueur de pub */ }
    }
  });
</script>

{#if show}
  <div class="ad-box" style="--ad-h: {height}px">
    <span class="ad-label">Publicité</span>
    <ins
      bind:this={insEl}
      class="adsbygoogle"
      style="display:block;width:100%;height:{height}px"
      data-ad-client={ADSENSE_CLIENT}
      data-ad-slot={adSlot}
    ></ins>
  </div>
{/if}

<style>
  .ad-box {
    max-width: 728px;
    margin: 28px auto;
    padding: 10px 12px 12px;
    min-height: calc(var(--ad-h) + 38px);
    border: 1px solid var(--border);
    border-radius: var(--r, 8px);
    background: var(--surface);
  }
  .ad-box:has(ins[data-ad-status='unfilled']) { display: none; }
  .ad-label {
    display: block;
    margin-bottom: 8px;
    font-family: 'Barlow Condensed', sans-serif;
    font-size: 0.62rem;
    letter-spacing: 0.28em;
    text-transform: uppercase;
    color: var(--dim);
  }
</style>
```

Notes d'implémentation :

- `window.adsbygoogle` est une queue : le `push({})` fonctionne même si le script n'est pas encore chargé.
- L'`<ins>` a une taille **fixe** (pas de `data-ad-format`) : Google sert une annonce qui rentre dans le cadre — jamais plus grand, zéro CLS.
- `data-ad-status="unfilled"` (posé par Google quand aucune annonce ne remplit l'unité) replie tout le cadre via `:has()`.
- `pushed` n'est pas un `$state` : garde interne, pas de réactivité nécessaire.

### Task 3: Chargement conditionnel du script dans le layout

**Files:**

- Modify: `src/routes/(site)/+layout.svelte:75-97` (onMount)

**Interfaces:**

- Consumes: `ADSENSE_CLIENT` de Task 1, `currentUser`/`authReady` existants.
- Produces: script `adsbygoogle.js` présent dans le DOM pour tout visiteur non-admin (la CMP Google est servie par ce script).

- [ ] **Step 1: Ajouter l'import et la fonction d'injection**

Dans le `<script>` de `src/routes/(site)/+layout.svelte`, ajouter après les imports existants :

```js
import { ADSENSE_CLIENT } from "$lib/ads.js";
```

puis ajouter avant `onMount(async () => {` :

```js
let adsLoaded = false;
function loadAdsScript() {
  if (adsLoaded || currentUser?.profile?.role === "super_admin") return;
  adsLoaded = true;
  const s = document.createElement("script");
  s.async = true;
  s.crossOrigin = "anonymous";
  s.src = `https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=${ADSENSE_CLIENT}`;
  document.head.appendChild(s);
}
```

- [ ] **Step 2: Appeler après résolution de l'auth**

Dans le `onMount`, remplacer :

```js
    authReady = true;
    sb.auth.onAuthStateChange(async (event, session) => {
```

par :

```js
    authReady = true;
    loadAdsScript();
    sb.auth.onAuthStateChange(async (event, session) => {
```

Note : si un admin se déconnecte, le script se chargera à la prochaine navigation complète — pas de gestion dynamique du logout (YAGNI, l'admin recharge la page).

Attention au chemin early-return : `if (!sb) { authReady = true; return; }` en tête de `onMount` — ajouter `loadAdsScript();` avant ce `return` aussi :

```js
if (!sb) {
  authReady = true;
  loadAdsScript();
  return;
}
```

1. Session non connectée : l'onglet Réseau montre `adsbygoogle.js?client=ca-pub-6495356963886902` chargé.
2. Connecté en super_admin : aucune requête `pagead2.googlesyndication.com`.
